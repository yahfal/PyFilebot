# Файловый Telegram-бот

Это многофункциональный бот для управления файлами на сервере через Telegram.

## Возможности

- **Просмотр файлов и папок:** Удобная навигация по файловой системе с помощью кнопок.
- **Загрузка файлов:** Просто отправьте файл боту, и он сохранится в текущей папке.
- **Удаление файлов:** Удаляйте файлы с подтверждением, чтобы избежать случайных действий.
- **Безопасность:** Доступ к боту ограничен списком разрешенных пользователей (`ALLOWED_USER_IDS`), а навигация ограничена корневой папкой (`ROOT_PATH`).

## Требования

Перед использованием установите библиотеку `python-telegram-bot`:
```bash
pip install python-telegram-bot
```

## Настройка

Перед запуском бота отредактируйте файл `config.txt`:

1.  **TOKEN**
    - Укажите токен вашего Telegram-бота.
    - `TOKEN = "123456:ABC-DEF1234567890"`

2.  **ROOT_PATH**
    - Укажите путь к папке на сервере, которой будет управлять бот.
    - `ROOT_PATH = "./files"`

3.  **ALLOWED_USER_IDS**
    - **(Обязательно!)** Перечислите через запятую ID пользователей Telegram, которым разрешен доступ к боту.
    - `ALLOWED_USER_IDS = "111111111, 222222222"`
    - Если оставить поле пустым, доступ будет запрещен для всех.

## Запуск

После установки зависимостей и настройки `config.txt` запустите бота:
```bash
python bot.py
```
